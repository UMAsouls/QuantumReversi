# 量子オセロ
[プレイ動画](https://youtu.be/Pcocyi0pGNA)

## 概要
石の白黒がターン毎に変化するオセロです。
石の色が確定しないため、石が置ける場所も毎回予測困難になります。
ただし、石が変わる確率には偏りがあり、石をひっくり返すことでその確率を反転させることができます。
自分側の色となる確率が高い石を多くし、最終的に自分が勝つ期待値を大きくすることが目的のゲームになっています。

## 開発情報
- 開発期間：1週間
- 開発人数：3人
- 使用技術：Unity, Unitask, Vision Transformer
- 担当：チームの進行管理、ゲームシステムの設計・実装、UI実装

## 工夫した点
### UIについて
プレイヤーが現在選択しているマスを白く点滅させ、石を置けるマスを強調表示しました。これにより、プレイヤーが現在の操作対象や、次に可能な行動を直感的に判断できるようにしました。

また、画面右上の「Change Mode」ボタンを押すことで、それぞれの石が白色に変化する確率を確認できる機能を実装しました。盤面の状態だけでなく、確率情報も確認しながら戦略を考えられるようにしています。

### 対戦AIについて
チームメンバーがVisionTransformerによる深層強化学習で作成した学習済みモデルを、ONNXとSentisライブラリを用いてUnity上に組み込みました。

ゲームの盤面情報をAIへの入力形式に変換し、AIが選択した行動をゲーム内の操作として反映する処理を実装することで、プレイヤーがゲーム上でAIと対戦できるようにしました。

## 操作方法
盤上で左クリック：石を置く
画面右上の「Change Mode」ボタンをクリック：石が白色に変わる確率を表示
